# BooruNova v1.8.7

## 更新

- **新图标**：四颗新星沿一条不闭合的圆轨旋转排布，拖尾由深到淡、由粗到细；配色改为柔和的
  雾紫 → 雾蓝渐变（不再用又深又纯的紫），Android 13+ 主题图标同步重绘。
- **新启动动画**：四颗新星从四个方向同时出现，顺时针螺旋飞向中心，落位成图标后淡出交还界面。
- **凭据安全**：站点的 apiKey / 登录口令改存系统安全存储（Keystore 加密），启动时一次性迁移。
- **协议**：项目由 MIT 改为 GNU AGPL-3.0。

## 修复

- Android 8/9 缺少相册权限，导致下载必然失败。
- 本地数据损坏恢复时会把健康的库一并关掉且不再重开。
- danbooru / e621 的四档评级筛选不生效。
- 瀑布流滚动时瓦片串图（元素复用显示旧图）。
- 同引擎的镜像站无法添加，或编辑到错误的对象。
- 备份导出/导入的可达性、完整性与容错问题。
- 下载的取消/重试/卡死判定、hosts 映射与证书校验、分页去重等中低危项。

## 安装

- `app-arm64-v8a-release.apk`：绝大多数手机（约 19 MB，推荐）。
- `app-release.apk`：模拟器或少数 x86_64 设备（约 37 MB）。

签名证书未变，已安装旧版本可直接覆盖升级。
