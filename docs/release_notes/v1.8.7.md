# BooruNova v1.8.7

四颗新星的品牌图标、一批审计修复，以及项目协议更换为 GNU AGPL-3.0。

## 品牌

- **新图标**：四颗新星沿一条**不闭合的圆轨**旋转排布，拖尾由深到淡、由粗到细，环心一点暖光。
  配色换成柔和的雾紫 → 雾蓝渐变（不再是又深又纯的紫），48/72/192px 各档都做过缩放核对。
  Android 13+ 主题图标（单色版）同步重绘。
- **新启动动画**：四颗新星从四个方向同时出现 → 顺时针螺旋飘向中心、拖尾随之拉长 → 落位成图标
  → 淡出交还界面。全程 1.25s，不阻塞启动、不拦触摸；原生 splash 与动画使用同一画布尺寸，交接不跳尺寸。

## 修复（审计 A/B 批）

- **H1** Android 8/9 缺少相册权限 → 下载必然失败：补齐旧版本权限声明与请求路径。
- **H2** 本地库损坏恢复会把健康的 box 一并关闭且永不重开：恢复流程改为只隔离损坏的那一个。
- **H3** danbooru / e621 的四档评级迁移（2024 新口径）未处理：评级筛选与安全模式按新四档工作。
- **H4** 瀑布流瓦片无 key + gaplessPlayback → 滚动时元素复用显示旧图：瓦片按帖子身份重建。
- **H5** 模板「已添加」按引擎类型判定 → 同引擎的镜像站无法添加、编辑到错对象：改按站点实例判定。
- **H6** 备份缺陷群：导出/导入的可达性、完整性、容错与语义统一（凭据仍不写入备份）。
- **凭据安全**：站点的 apiKey / 登录口令不再以明文存放在本地库，改存系统安全存储
  （Android Keystore 加密）；首次启动做一次性迁移，读回复核通过后才抹除旧明文，
  复核失败则保留原样（宁可留明文也不丢 Key）。
- 另有中低危修复与回归守卫：下载的取消/重试/停滞看门狗、下载目录回退、hosts 映射与 TLS 校验、
  引擎能力声明与探测签名（按类型要求响应特征全部命中）、分页状态机（去重/竞态/夹取停止）等。

## 协议

- 项目协议由 MIT 改为 **GNU AGPL-3.0**：可自由使用、研究、修改与再分发，但分发或通过网络
  提供服务的衍生版本必须以同一协议开源，并提供完整对应源代码。第三方依赖仍遵循各自协议。
- `lib/` 下全部源文件补了 SPDX 标头（`AGPL-3.0-or-later`）。

## 安装

- `app-arm64-v8a-release.apk` —— 推荐，绝大多数手机（约 19 MB）。
- `app-release.apk` —— 通用包（arm64 + x86_64），模拟器或少数设备用（约 38 MB）。
- `SHA256SUMS.txt` —— 两个包的 SHA-256。
- `symbols.tar.gz` —— 本次构建的调试符号：应用内「设置 → 关于 → 导出诊断日志」给出的崩溃栈
  需要它才能还原成可读位置，请与对应版本一起留存。
- 签名证书未变，已安装旧版本可直接覆盖升级，无需卸载。
