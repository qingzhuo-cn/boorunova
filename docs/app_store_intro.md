# BooruNova

**一款开源的 Android 端 Booru 图站聚合浏览器。**

BooruNova 将多个 Booru 图站整合进同一个应用，用统一的搜索栏、统一的时间线、统一的收藏与下载，取代过去在多个应用和移动网页之间来回切换的体验。

纯原生 Flutter 实现，数据全部留在本地——不注册、不登录、不上传，也不依赖任何应用商店。

---

## 核心特性

### 浏览体验

- **多站点聚合** — 一个应用浏览所有已配置的图站
- **一键切换站点** — 点搜索栏左侧的站点图标即可在服务器之间跳转，不必离开当前时间线
- **瀑布流时间线** — 2–6 列可调网格（重启后仍保留），无缝无限滚动
- **全屏查看器** — 双指缩放、滑动翻页、幻灯片模式，跟手下滑手势即可关闭
- **长按速览** — 网格中长按即可浮起大图预览，松手即关，无需进入详情页
- **探索** — 热门 / 最新 / 随机，不输入标签也能逛
- **图集** — 浏览图片合集，仅在站点确实支持时显示入口
- **分类标签** — 画师 / 角色 / 版权 / 通用 / 元数据，五色区分一目了然

### 搜索

- **标签自动补全** — 防抖输入，按站点缓存建议
- **热门标签** — 实时拉取当前站点的热门标签
- **可编辑查询** — 搜索后点击搜索栏即可在原有标签基础上继续修改
- **搜索历史** — 保留最近 20 条查询，一键重新搜索
- **排序与分级过滤** — 相关度 / 分数 / 日期 / 分级，直接内置于查询

### 收藏与下载

- **收藏** — 按站点独立追踪
- **下载到相册** — 可选采样图或原图画质
- **回看历史与下载** — 点任意记录即可重新查看、分享，或用其他应用打开
- **批量操作** — 多选后批量收藏、下载、分享

### 个性化

- **主题** — 浅色 / 深色 / 午夜，自定义强调色
- **中英双语** — 界面与提示完整双语，设置中随时切换
- **可配置手势** — 滑动 / 点按 / 长按动作均可自定义
- **减少动画** — 需要时把页面转场改为瞬时切换
- **标签黑名单** — 屏蔽不想看到的内容
- **自定义 Hosts 映射** — 在受限网络环境下访问站点，且不破坏 HTTPS

### 数据管理

- **完整备份与恢复** — 站点、收藏、历史、黑名单、设置一键导出导入
- **缓存管理** — 一键回收存储空间
- **首次启动引导** — 全新安装时的简短上手

## 技术特点

- **网络层集中配置** — 超时、UA、认证头与 hosts 映射统一在 `DioFactory`，一处修改全网生效
- **hosts 映射作用在连接层** — 只替换 TCP 连接的目标 IP，请求 URL 保持原始域名，因此 query 参数不会丢失，HTTPS 的 SNI 与证书校验也照常工作
- **引擎薄封装** — 每个引擎只声明端点和解析器，共用同一个请求基类
- **测试覆盖五层** — 各引擎解析器、翻页状态机、下载并发写入、跨站点 id 隔离、hosts 连接映射（含对本地自签证书服务器的真实 TLS 握手）
